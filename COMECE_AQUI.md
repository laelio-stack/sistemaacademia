## 🎯 Primeiro Treino (Tutorial):

### Passo 1: Ir para Alunos
Clique em **👥 Alunos** no menu lateral.

### Passo 2: Cadastrar Aluno
```
Nome: João Silva
Clique: "Cadastrar Aluno"
```

### Passo 3: Ir para Treinos
Clique em **💪 Treinos**.

### Passo 4: Registrar Treino
```
1. Selecione: João Silva
2. Tipo: A
3. Exercício 1:
   - Nome: Supino Reto
   - Peso: 80
   - Séries: 4
   - Clique: ➕ Adicionar
4. Exercício 2:
   - Nome: Rosca Direta
   - Peso: 30
   - Séries: 4
   - Clique: ➕ Adicionar
5. Clique: 💾 Salvar Treino
```

### Passo 5: Ver Evolução
Clique em **📈 Evolução**:
```
1. Selecione: João Silva
2. Selecione: Supino Reto
3. Veja o histórico e gráfico!
```

### Passo 6: Ver Relatório
Clique em **📋 Relatórios**:
```
1. Selecione: João Silva
2. Veja o relatório completo
3. Clique: 📥 Exportar para CSV
```

## 💡 Dicas Iniciais

1. **Comece pequeno**
   - Cadastre 2-3 alunos
   - Registre alguns treinos
   - Depois expanda

2. **Use nomes consistentes**
   - "Supino Reto" (não apenas "Supino")
   - Facilita busca e evolução

3. **Registre sempre**
   - Logo após o treino
   - Mais preciso e fácil de lembrar

4. **Acompanhe regularmente**
   - Veja o progresso
   - Mantenha-se motivado

5. **Exporte regularmente**
   - Backup dos dados
   - Compartilhe com alunos

## ❓ Perguntas Rápidas

**P: Preciso instalar algo?**
R: Não! Funciona direto no navegador.

**P: Precisa internet?**
R: Não! Tudo é offline.

**P: Onde ficam meus dados?**
R: No navegador (localStorage).

**P: Posso perder dados?**
R: Apenas se limpar cache. Exporte para backup!

**P: Funciona em celular?**
R: Sim! Use em modo tela cheia.

**P: Como faço backup?**
R: Exporte relatórios em CSV ou copie localStorage.

**P: Posso compartilhar?**
R: Sim! Exporte dados em CSV.
